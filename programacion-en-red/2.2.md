# Tema 2. Protocolo IP (red)

**IP** (*Internet Protocol*, definido en el [RFC 791](https://www.rfc-editor.org/rfc/rfc791)) trabaja a nivel de red y proporciona un servicio de datagramas **sin conexión** y **no confiable**.

- **Servicio de datagramas**: cada paquete se gestiona de forma independiente. Cada uno lleva su dirección de destino y la red lo encaminará como pueda.
- **Sin conexión**: no se establece una sesión, es decir, no hay una conexión previa entre remitente y destinatario antes de empezar a intercambiar información.
- **No confiable**: IP hace lo posible para que el paquete llegue bien, pero puede ocurrir que:
  - no llegue nunca (se pierda o se elimine),
  - llegue duplicado,
  - llegue más tarde que otros paquetes enviados posteriormente por el mismo remitente al mismo destinatario (fuera de secuencia o retrasado).

  Tampoco asegura la integridad de los datos, que pueden llegar corruptos. Lo que sí se verifica, mediante *checksum*, es la integridad de las cabeceras.

## Estructura del paquete IP

Cada paquete IP consta de un **encabezado** y un **contenido** (los datos que se quieren transmitir, enviados desde los protocolos superiores). El encabezado tiene varios campos (versión, longitud, checksum, tipo, flags, etc.), pero hay tres fundamentales:

- **Dirección IP de origen**
- **Dirección IP de destino**
- **TTL** (*Time to Live*, tiempo de vida): número de saltos (enrutadores o *routers*) que se permite atravesar al paquete. Cada enrutador decrementa este valor en al menos 1 y, cuando llega a 0, descarta el paquete para evitar que circule indefinidamente por la red. Además de eliminarlo, envía mediante ICMP (*Internet Control Message Protocol*) un aviso de tipo *Tiempo excedido* a la dirección IP de origen.

## API de `java.net` (nivel de red)

### Clase `InetAddress`

`InetAddress` es la clase de `java.net` que representa una **dirección IP** (IPv4 o IPv6), opcionalmente asociada al nombre de host con el que se ha obtenido. Es la abstracción básica de la capa de red en Java: identifica a un equipo (o a una de sus interfaces) en una red, **sin incluir el puerto**, concepto que aparece en el nivel superior de transporte.

Características principales:

- **No tiene constructores públicos**. Las instancias se obtienen mediante métodos estáticos como `getByName()`, `getAllByName()`, `getByAddress()`, `getLocalHost()` o `getLoopbackAddress()`.
- Tiene dos subclases: **`Inet4Address`** (4 bytes) e **`Inet6Address`** (16 bytes).
- Es **inmutable**: una vez creada, la dirección no cambia.
- Permite **resolver nombres** mediante DNS (de nombre a IP con `getByName()` y de IP a nombre con `getHostName()`), y guarda en caché los resultados.
- Ofrece métodos para **consultar y clasificar** la dirección: `getHostAddress()`, `getAddress()`, `isLoopbackAddress()`, `isSiteLocalAddress()`, `isMulticastAddress()`, `isReachable()`...
- Los métodos que consultan al DNS lanzan `UnknownHostException` si el nombre no se puede resolver.

Al imprimirla con `println`, se muestra con el formato `nombre/IP` (por ejemplo, `google.es/173.194.41.247`). Si no se conoce el nombre, aparece solo `/IP`.


```java
public static InetAddress getLocalHost() throws UnknownHostException
```
Devuelve la dirección IP local.

```java
public static InetAddress getByName(String host) throws UnknownHostException
```
Devuelve la dirección IP del nombre de host especificado. Si se pasa una IP, únicamente se valida su formato. Si se pasa `null`, devuelve la dirección del interfaz *loopback*.

```java
public static InetAddress[] getAllByName(String host) throws UnknownHostException
```
Devuelve un array con todas las direcciones IP del host indicado.

```java
public static InetAddress getByAddress(byte[] addr) throws UnknownHostException
```
Devuelve una `InetAddress` a partir de un array de 4 o 16 bytes, según se trabaje con IPv4 o IPv6 (`Inet4Address` / `Inet6Address`).

```java
System.out.println(InetAddress.getLocalHost());                      // MIMAQUINA/192.168.1.34
System.out.println(InetAddress.getByName(null));                     // localhost/127.0.0.1
System.out.println(InetAddress.getByName("ieschandomonte.edu.es"));  // ieschandomonte.edu.es/82.98.160.22
System.out.println(InetAddress.getByName("google.es"));              // google.es/173.194.41.247
System.out.println(InetAddress.getByAddress(new byte[]{(byte) 192, (byte) 168, 33, 25})); // /192.168.33.25

InetAddress[] ips = InetAddress.getAllByName("google.es");
for (InetAddress ip : ips) {
    System.out.println(ip); // google.es/173.194.41.248, google.es/173.194.41.247, ...
}
```

Las direcciones de los ejemplos son orientativas y variarán según el momento y la red.

Todos estos métodos lanzan una `UnknownHostException` si no se puede obtener la dirección IP.
